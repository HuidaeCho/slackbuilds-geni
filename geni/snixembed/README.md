# snixembed

[snixembed](https://git.sr.ht/~steef/snixembed) is a proxy that bridges an XEmbedded system tray (e.g., stalonetray) with StatusNotifierItem applications (e.g., Remmina).

Without this proxy, `remmina -i` exits when the last session window is closed, even though its icon remains visible in stalonetray.

Source code: https://git.sr.ht/~steef/snixembed/archive/0.3.3.tar.gz
